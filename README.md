# 🌤️ Weather Dashboard

A clean, modular weather dashboard built with vanilla JavaScript. Search for any city, view current weather, 5-day forecast, and get auto-complete suggestions.

🔗 **[Live Demo](https://your-demo-link.com)**

---

## ✨ Features

- **Search Weather** – Search any city worldwide
- **Current Weather** – Temperature, feels like, wind speed, humidity, sunrise/sunset
- **5-Day Forecast** – Daily min/max temperatures and conditions
- **Unit Toggle** – Switch between °C and °F without new API calls
- **Search History** – Last 5 cities saved in localStorage
- **Auto-Complete** – City suggestions as you type (debounced)
- **Caching** – 10-minute cache to reduce API calls
- **Responsive** – Works on desktop, tablet, and mobile
